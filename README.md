# Urbanic

A redesigned fashion e-commerce website with a fresh, modern UI and advanced animations for an engaging shopping experience.

 Live Link : https://kanikasahu21.github.io/urbanic/

---

## Features
- Interactive product grid with hover animations
- Dynamic filtering and sorting functionality
- Add-to-cart visual effects
- Smooth scrolling and storytelling animations
- 
---

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Animations:** GSAP, ScrollTrigger, Locomotive.js, Shery.js
- **Version Control:** Git, GitHub
